PERSONAL ASSISTANT ANDROID — BUILD WITHOUT ANDROID STUDIO
========================================================

This project can be built entirely in a web browser through GitHub Actions.
No Android Studio, emulator, Android SDK, Java, or Gradle installation is required on your PC.

IMPORTANT VERSION NOTE
----------------------
This package contains the previously prepared Android v3.6.66 source. It does not yet contain
all features added later to the Windows v3.7.5 application.

BROWSER-ONLY BUILD STEPS
------------------------
1. Create or sign in to a GitHub account.
2. Create a new EMPTY repository. Do not add README, .gitignore, or license.
3. Extract this ZIP on your PC.
4. Open the extracted PersonalAssistantAndroid_v3_6_66_NoStudio folder.
5. Upload all files and folders to the root of the GitHub repository, including the hidden
   .github folder. The repository root must directly contain:
       app/
       .github/
       build.gradle
       settings.gradle
6. Commit the uploaded files.
7. Open the repository's Actions tab.
8. Choose "Build Android APK".
9. Press "Run workflow". If it already ran automatically, open the latest run.
10. Wait until the build shows a green check mark.
11. At the bottom of the completed run, download the artifact named:
       PersonalAssistant-Android-debug-APK
12. Extract the downloaded artifact ZIP. It contains app-debug.apk.
13. Copy app-debug.apk to your Android phone and install it.

PHONE INSTALLATION
------------------
Android may ask permission to install unknown apps. Grant permission only to the file manager
or browser used to open this APK, install it, and then disable that permission afterward.

COMMON UPLOAD ERROR
-------------------
If the Actions tab does not show "Build Android APK", the .github/workflows/build-apk.yml file
was not uploaded at the repository root. Upload the .github folder again.
