Personal Assistant Android v3.8.4

This package is a targeted update of Android v3.8.3.

Dashboard calendar:
- Today card continues to display current Shamsi and Gregorian dates.
- Week / Month / Year mode buttons remain unchanged.
- Previous and Next continue to navigate according to the selected mode.
- Week view now displays all seven days in TWO rows for better readability on phone screens:
  Row 1: Saturday, Sunday, Monday, Tuesday
  Row 2: Wednesday, Thursday, Friday
- No horizontal scrolling is required to see the full week.

All other v3.8.3 features are preserved unchanged.
