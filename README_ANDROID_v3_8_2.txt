Personal Assistant Android v3.8.2

This is a targeted update of Android v3.8.1.

Build with GitHub Actions:
1. Upload the project contents to the repository root.
2. Ensure .github/workflows/build-apk.yml exists.
3. Open Actions -> Build Android APK -> Run workflow.
4. Download PersonalAssistant-Android-v3.8.2-debug-APK.
5. Install app-debug.apk over the existing app to preserve Android app data.

New in 3.8.2:
- Direct/batch deletion of completed tasks.
- Calendar navigation rows fixed so Week/Month/Year and Previous/Today/Next are all visible.
- Removed "Week containing ...".
- Multi-note storage with title, body, edit, delete, and See all notes.
