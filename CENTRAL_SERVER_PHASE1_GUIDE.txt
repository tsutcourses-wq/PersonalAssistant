PERSONAL ASSISTANT ANDROID v3.8.0 — CENTRAL SERVER PHASE 1

In Settings, open Central server and configure the same server used by Windows.
For a server running on another computer in your local network, enter that
computer's LAN address, for example http://192.168.1.10:8000. Do not enter
127.0.0.1 on the phone.

Use Download before starting work on the phone. Use Upload when finished. The
snapshot contains the database and Android-managed documents. Revision conflicts
are detected and a local backup is created before downloaded data is applied.

Use one device at a time in Phase 1. HTTPS is required before internet/VPS use.
