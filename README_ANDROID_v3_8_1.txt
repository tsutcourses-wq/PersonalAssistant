Personal Assistant Android v3.8.1

This package is a targeted modification of the user-supplied Android v3.8.0 ServerReady project. It keeps the underlying v3.8.0 codebase and data compatibility while simplifying the Android-facing interface as requested.

GitHub build:
1. Upload the contents of this folder to the repository root, including the hidden .github folder.
2. Open GitHub Actions.
3. Run Build Android APK.
4. Download PersonalAssistant-Android-v3.8.1-debug-APK.
5. Install app-debug.apk over the existing app to preserve the existing local database.

Important: do not uninstall the existing Android app first if you need to preserve its local Android database.
