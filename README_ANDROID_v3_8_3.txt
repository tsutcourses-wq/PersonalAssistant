Personal Assistant Android v3.8.3

This package is a targeted update of Android v3.8.2.

Dashboard calendar:
- A Today card above the calendar displays the current Shamsi and Gregorian dates.
- Week / Month / Year mode buttons are retained.
- Previous and Next navigate according to the selected mode.
- The Today navigation button was removed as requested.
- Week view fits all seven days on screen at once instead of requiring horizontal scrolling.

Notes:
- The explanatory description below Notes was removed.
- Titled notes, Save note, See all notes, edit and delete remain unchanged.

All other v3.8.2 features are preserved.
